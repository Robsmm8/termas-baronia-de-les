# Termas Baronía de Les · web

Prototipo de la nueva web de Termas Baronía de Les (Les, Val d'Aran), preparado para Carpanta.

Web publicada: https://robsmm8.github.io/termas-baronia-de-les/

## Estructura

- `index.html`: toda la web (Inicio, Circuito termal, Nuestras aguas, Tarifas y horarios, Contacto) y la reserva en 3 pasos.
- `img/`: fotos y logo del balneario, tomados de termasbaroniadeles.com.

## Idiomas

Catalán (por defecto), español, francés e inglés. Todos los textos están en el objeto `L` del script de `index.html`, un bloque por idioma (`ca`, `es`, `fr`, `en`).

## Pendiente de validar con el balneario

- Tarifas: son las publicadas en noviembre de 2021.
- Política de cancelación (propuesta: gratuita hasta 24 h antes).
- Precio de los packs circuito + masaje (ahora es la suma sin descuento).
- Fotos de vaporarium, duchas frías y pediluvio.
- Revisión nativa de las traducciones al catalán y al francés.
- La reserva y el formulario de contacto son de demostración: no envían nada.
